# hostrecap-release
HostRecap is a free, local-first AI meeting notes and offline transcription app for Windows 10 and 11. It captures mic and system audio via Windows WASAPI with zero meeting bots, processes summaries locally on CPU or GPU even offline, and lets you click any transcript quote to replay local WAV audio proof.
